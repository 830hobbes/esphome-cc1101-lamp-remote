# esphome-cc1101-lamp-remote
Control a 433 MHz RF LED lamp from Home Assistant with an ESP32 + CC1101 via ESPHome. Includes the reverse-engineered OOK protocol (Gaonitz CLED-5501C, FCC 2BD2C-ZZ02DY01007) and an RTL-SDR workflow for cloning your own remote — with the traps documented: inverted polarity, constant bit period, preamble structure.
